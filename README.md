Проект SkyFitnessPro. Реализован от верстки макета до деплоя.

Ознакомиться с макетом можно по ссылке: https://www.figma.com/design/efIqPMajoJgo2FIfbFbn1G/SkyFitnessPro?node-id=0-1&t=o5Edo4mUNIOCrijC-1. Документация по API находится здесь: https://github.com/GlebkaF/webdev-hw-api/blob/main/pages/api/fitness/README.md

Технологии React TypeScript — базовый инструмент для реализации приложения. Next.js — фреймворк для разработки. ESlint, Prettier — инструменты для регулирования определённого стиля написания кода.
